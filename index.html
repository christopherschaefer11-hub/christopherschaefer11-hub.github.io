🚀 Host for Free on GitHub Pages (Step-by-Step)

GitHub Pages turns your single index.html file into a permanent, mobile-friendly https:// link you can text or email to any coworker without firewall blocks.

Once your GitHub Pages site is live, paste its URL here (or open the app directly from that URL) so every shared link uses your live address automatically:

Step 1: Create a free GitHub account & New Repository Sign in at github.com/new ↗. Set the Repository Name to nhl-trip-planner (or sports-trip-planner), choose Public, check Add a README file, and click Create repository.
Step 2: Upload your index.html file Inside your new repository, click Add file → Upload files. Drag and drop your downloaded index.html file (from the zip package), then click the green Commit changes button at the bottom.
Step 3: Turn on GitHub Pages Click the Settings tab at the top of your repository, then click Pages in the left sidebar (GitHub Pages Quickstart ↗). Under Build and deployment → Branch, change None to main (and folder / (root)), then click Save.
Step 4: Text or Email your live link! Wait ~60 seconds and refresh the Pages settings screen. Your live link will appear as https://<your-username>.github.io/nhl-trip-planner/. Anytime you click 🔗 Share Trip Link, 💬 Text / SMS, or ✉️ Email in this app, your selected teams, travel radius, and pinned trips are embedded right into the link!

Built for NHL road trips today, with a normalized multi-league engine ready for Pro + NCAA crossover itineraries.
